# Ardent World - Static Website

A standalone HTML/CSS/JavaScript website for Ardent World.

## Directory

```text
ardent-world-static/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── script.js
├── assets/
│   └── ardent-world.png
└── README.md
```

## Run locally

No Node.js is required.

Open `index.html` directly in a browser, or use a simple local server:

```bash
python -m http.server 8000
```

Then open:

http://localhost:8000

## Before publishing

Edit these values in `index.html`:

- `info@ardentworld.com`
- `+919999999999`
- Services
- Technologies
- Projects
- Company description

Replace the placeholder contact details with the real company details.

## Static hosting

Upload the complete contents of this folder to:

- GitHub Pages
- AWS S3 static website hosting
- Cloudflare Pages
- Netlify
- Any normal web server

The site does not require a backend.
